Four decisions that shaped it

Typed contracts between services

Encore generates the API contracts between all 14 services, so mismatched payment-webhook fields and order-status changes failed at compile time instead of in UAT.

Payments behind one interface

A four-method PaymentGateway interface is implemented by FPX (RSA signatures) and Cybersource (HMAC). Every webhook verifies its signature before an order is marked paid, and new banks plug in without touching the order flow.

Offline-first ordering

The cart, catalogue and profile live on the device. Failed requests queue and retry when the connection returns, and the cart is reconciled with the server, so patchy mall Wi-Fi never loses an order.

Sessions you can revoke per device

Short-lived access tokens plus one refresh token per device, stored hashed. Admins can sign out a single lost phone, and tokens rotate on every renewal.
